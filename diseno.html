Ejercicio de identidad de marca

Tueste Norte

Proyecto conceptual · marca ficticia

Concepto visual para una tostaduría de café ficticia de Monterrey. El ejercicio parte de una marca artesanal, directa y cercana, y explora cómo darle una expresión gráfica consistente.

Concepto

Definición de personalidad, dirección visual y tono de una marca de café.

Identidad

Exploración de logotipo, tipografía y un sistema de color reducido.

Aplicaciones

Propuestas de empaque y otras piezas de presentación de marca.

Transparencia: Tueste Norte es un ejercicio personal de diseño; no es una empresa cliente ni una marca comercial operada por mí. Las piezas gráficas definitivas se incorporarán como una galería visual cuando esté lista la documentación del caso.
